# Slashlib для Android (Kotlin, Material Design 3)

Неофициальный клиент. **Android 5.0+ (API 21)**. Один APK работает и на armv7 (armeabi-v7a), и на arm64 (arm64-v8a):
в проекте нет нативного кода.

## Как собрать
GitHub → вкладка Actions → build-android → Run workflow. APK: внизу запуска, Artifacts → `slashlib-apk`.
(Своего Gradle-wrapper в проекте нет, workflow ставит Gradle 8.5 сам. Локально: JDK 17 + Gradle 8.5, `gradle :app:assembleRelease`.)
APK подписан отладочным ключом — можно ставить сразу; при обновлении с другой сборки Android может потребовать сначала удалить старую.

## Что есть
- Нижняя панель M3: Главная · Поиск · Избранное · Закладки · Аккаунт.
- Главная: сверху «Продолжить чтение» с полосой и процентами, ниже случайные подборки по жанрам с тегами-плашками.
- Поиск с подгрузкой, экран тайтла (обложка, «О тайтле», главы, избранное), закладки и «Недавние».
- Читалка: лента или страницы (→ / ←), зум в постраничном режиме, ползунок страниц, закладка, панели скрываются при листании,
  фон страницы, затемнение, «не гасить экран». Длинные страницы режутся на полосы и декодируются по частям.
- Тема: светлая / тёмная / системная, цвет акцента (или Material You на Android 12+), MangaLib одним переключателем.
- Синхронизация закладок, избранного, «Недавних» и прочитанных глав через приватный Gist GitHub — формат такой же, как в
  iOS-версии, поэтому данные синхронизируются и между Android и iOS.

## Чего пока нет
Скачивания глав для офлайн-чтения, режима энергосбережения и профилей «телефон/планшет». Адреса и поля API —
в `Config.kt` и `Api.kt` (помечено «ПРОВЕРИТЬ»).
